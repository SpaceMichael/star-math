# 星星數學小勇士

以小一上學期的數學練習為基礎，製作給孩子玩的十級互動數學小遊戲。

## 開始遊戲

直接以瀏覽器開啟 `index.html` 即可，無需安裝套件、啟動伺服器或連接網絡。

首頁提供中文、英文、數學、科學、人文五個科目。中文、英文、數學已開放；科學、人文標示「即將推出」。可從各科歡迎頁或成績頁返回科目選單；重新選科會從第 1 級開始。

## 中文及英文題庫

- 原始 PDF 分別保存在 `教材題目-中文\考試範例-中文.pdf` 及 `教材題目-英文\考試範例-英文.pdf`，不改動原件。
- `language-question-bank.js` 收錄中文 17 題（包含 3 道明確標記的原卷例題）及英文 20 題，每題附 PDF 檔名、頁碼、題號、答案及固定選項。
- `教材題目-中文` 亦保存 `語基工_Page1.pdf`、`語基工_Page2.pdf`。新增 4 道看圖選名詞及 3 道名詞填充原題，答案依工作紙批改內容整理。看圖題只顯示裁出的原題圖畫，不顯示姓名欄或已填答案；三空格填詞題保留完整句子並一次選出三個答案。
- 每級隨機抽 10 道不同題，優先抽未出現過的題目；不足時重用原題，不生成新題。兩科亦設 10 級，但不代表難度遞增。
- 中文只收錄清楚可讀、可判分的題目；以「XX」代替正文的閱讀及重組句子題、沒有完整內容的開放題不收錄。中文沒有另附答案本，答案依題意整理，並非官方答案；固定選項為遊戲作答方式。
- 英文選用原卷已有答案的閱讀、填詞、文法、改錯及押韻題，轉為選擇作答；閱讀題會顯示完整相關短文。原卷含已填答案的插圖連線題和自由寫作題暫不收錄，以免直接展示答案或錯誤自動判分。

## 數學遊戲內容

- 每級隨機抽出十題，答對一題獲得一粒星星，最高十分。
- 完成十題後可再玩本級或挑戰下一級，最多挑戰十級；完成第十級後可重新挑戰。
- 題目從固定題庫抽取，優先使用尚未出現過的題目；題庫不足以支援十級完全不重複，因此用完後會重新抽選。
- 答對時會播放提示音，完成挑戰後會有慶祝音效；右上角可關閉音效。
- 數學共 107 道固定題目：`question-bank.js` 原有 84 題，`math-additional-bank.js` 新增 23 題，每題都標明來源、頁碼和題號；遊戲不會自行生成題目或改動原題數字。填空及連線原題改為固定選項，方便孩子作答。
- `教材題目\Math_20261016_PDF.pdf` 保存七頁原卷。新增題目依印刷題面與批改內容核對，含 4 道附原圖的計算／分解題。原卷甲第 3 題「13 以內最大的奇數」與選項有矛盾（缺少 13），暫不收錄；帶手寫答案標記、未能乾淨分離的其他圖題及畫圖題也未收錄。
- A、B、C 三冊原題 PDF 收納在 `教材題目`，答案 PDF 和可搜尋文字版收納在 `教材答案`。
- 每級從固定題庫抽出 10 題，答案和選項亦直接取自題庫。選項次序會隨機排列，但題目內容和正確答案不變。
- C 冊第 6 頁第 1 題的三個小題共用 PDF 原圖。第 2 題「15 個小朋友」沒有原圖，遊戲會顯示標明為輔助圖的 15 個位置，並標出題目提及的小朋友，避免誤用顧客排隊圖。
- 配合桌面和手機畫面，亦支援鍵盤操作和減少動態效果偏好設定。

## 中文生字表

中文歡迎頁的「生字表」按鈕會一次顯示第 1、3、4、5 課全部 37 個字詞，按課文分組，可返回中文挑戰。生字不會當成自行生成的考題混進題庫。

- 原始 PDF：`教材-中文生字\中文重詞表_26_27.pdf`。
- 整理後的字詞：`chinese-vocabulary.js`；依原表順序保留各課字詞，畫面不顯示姓名欄。

## 英文生字表

英文歡迎頁的「生字表」按鈕會一次顯示全部 30 個字詞，按 This Is My Bear、Bird Colours、I Can 三份工作紙分組，各組列出來源 PDF。保留原表拼法及大小寫，包括 `colours`、`grey`、`September`，不顯示姓名或手寫內容；可按「返回英文」回到挑戰頁。

- 三份原始 PDF 保存於 `教材-英文生字`，保留原檔名。
- 整理後字詞在 `english-vocabulary.js`；中英文生字表分開顯示，不改動考題庫。

## 驗證

上述新增原始 PDF 包含個人資料，只保存於本機並以 `.gitignore` 排除，不隨 GitHub 公開版本發佈。GitHub 版本包含整理後的題庫、生字表與避開姓名欄的題目插圖，毋須原始 PDF 亦可遊玩。

已安裝 Node.js 時，可執行 `node --test tests\subjects.test.js`，驗證分科抽題、閱讀短文顯示、十級流程及返回選單。
