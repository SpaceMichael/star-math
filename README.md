# 星星數學小勇士

以小一上學期的數學練習為基礎，製作給孩子玩的十級互動數學小遊戲。

## 開始遊戲

直接以瀏覽器開啟 `index.html` 即可，無需安裝套件、啟動伺服器或連接網絡。

## 遊戲內容

- 每級隨機抽出十題，答對一題獲得一粒星星，最高十分。
- 完成十題後可再玩本級或挑戰下一級，最多挑戰十級；完成第十級後可重新挑戰。
- 題目從固定題庫抽取，優先使用尚未出現過的題目；題庫不足以支援十級完全不重複，因此用完後會重新抽選。
- 答對時會播放提示音，完成挑戰後會有慶祝音效；右上角可關閉音效。
- 題庫使用 `question-bank.js` 內的 84 道固定原題，每題都標明來源冊數、頁碼和題號；遊戲不會自行生成題目或改動原題數字。填空原題配上固定選項，方便孩子作答。
- A、B、C 三冊原題 PDF 收納在 `教材題目`，答案 PDF 和可搜尋文字版收納在 `教材答案`。
- 每級從固定題庫抽出 10 題，答案和選項亦直接取自題庫。選項次序會隨機排列，但題目內容和正確答案不變。
- C 冊第 6 頁第 1 題的三個小題共用 PDF 原圖。第 2 題「15 個小朋友」沒有原圖，遊戲會顯示標明為輔助圖的 15 個位置，並標出題目提及的小朋友，避免誤用顧客排隊圖。
- 配合桌面和手機畫面，亦支援鍵盤操作和減少動態效果偏好設定。
